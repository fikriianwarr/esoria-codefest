# Pemeriksaan Hasil Publik dan Sertifikat

`node scripts/live/audit-official-readiness.mjs` menjalankan audit baca-saja terhadap Auth, hasil kompetisi dan kelayakan sertifikat pada Firebase `esoria-codefest`. Alat ini tidak mengaktifkan akun, menulis hasil, menghapus data, atau menerbitkan sertifikat.

Untuk sertifikat asli, panitia harus menyelesaikan penilaian, mengesahkan hasil, dan menunggu waktu pengumuman. PDF hanya diterbitkan untuk entri yang memenuhi aturan backend. Dataset peserta dan hasil latihan tidak disertakan dalam rilis bersih ini.
